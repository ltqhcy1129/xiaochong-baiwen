就医提示
异宠看病最怕说不清。出门前把这几个东西备好，医生能省一半时间。

出门前，这几样带上

先找对地方

地图里信息常过期，先打电话问：接不接异宠、有没有对应物种的医生、今天在不在。

去过的医院

电话里先问清三件事

先打电话确认：是否接诊异宠、有没有对应物种的经验、当天是否有医生在。
搜索关键词用「城市 + 异宠医院 / 爬宠医生 / 鸟类医生」，比搜「宠物医院」有效。
兔子、龙猫、豚鼠属于「小哺乳」，很多猫狗医院不接；守宫、蛇、蜥蜴要找爬宠方向。
夜间和节假日先问急诊，避免白跑。路程超过 1 小时的，提前说明情况让医院准备。

见医生怎么说

按时间说：哪天开始、什么表现、怎么变化，比「它一直不舒服」有用得多。
主动交代饲养参数：温度、湿度、灯具、垫材、笼箱尺寸、最近有没有换环境。
交代喂食与排泄：吃了什么、多久没吃、粪便形态和颜色、最近一次排酸或蜕皮时间。
交代用药史：自己用过什么药、剂量、用了几天，包括网购的「驱虫药」和保健品。
带上记录：温湿度截图、体重变化、症状视频，比现场描述准确。

路上怎么带

用原饲养盒或透气的运输盒，不要用纸袋、塑料袋；盒内放一层熟悉的垫材。
爬宠与鸟类要保温：冬天用暖宝宝隔布贴在外壁，不要直接接触宠物。
途中不要喂食；兔、豚鼠等食草动物可带少量平时吃的干草。
减少颠簸与强光，盖一层透气布，但留出通风口。

这几件事别做

不要自行喂人用药：布洛芬、对乙酰氨基酚对多数异宠有致命风险。
不要为了「先观察」拖过夜：异宠体型小、代谢快，恶化常在几小时内。
不要强行灌食灌水：呛入气管会致命，尤其鸟类和小型哺乳类。
不要用「洗澡」「晒太阳」处理中暑或脱水，容易加重应激。
以上为就诊准备建议，具体诊疗请遵从执业兽医意见
